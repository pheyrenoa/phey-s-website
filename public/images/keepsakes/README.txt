Photos of real keepsakes for the "Things I Couldn't Throw Away" drawer.

How to use it:
1. Drop your photo file in this folder (jpg, png, or webp).
2. In src/content/photos.ts, add an entry with section: "keepsakes" and
   src: "/images/keepsakes/<your-file-name>".
3. In src/content/loves.ts, set photoId on the keepsake to that entry's id.
The drawer shows the photo instead of the drawing. No component changes needed.

Photos for page 1, "Who is Phey?" (Uzbekistan, moving to the US, portraits).

How to use it:
1. Drop your photo file in this folder (jpg, png, or webp).
2. Open src/content/photos.ts, find the matching photo id, and set
   src to "/images/about/<your-file-name>".
3. Update the alt text so it describes the real photo.
No component changes are needed.
